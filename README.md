# Empowered Scholars

Empowered Scholars is a Flask-based web application designed to support an education-focused community platform. The project includes profile management, collaboration listings, blog functionality, contact forms, and a user dashboard.

## Features

- User registration and authentication
- Personal profile and portfolio management
- Blog creation and browsing
- Collaboration/project posting and interest tracking
- Contact and inquiry forms
- Admin-style email notifications for submitted forms

## Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML/CSS/JavaScript
- Bleach for input sanitization

## Project Structure

- `main.py` — application logic and routes
- `templates/` — HTML pages
- `static/` — CSS, JavaScript, and media files
- `instance/` — local app data
- `requirements.txt` — Python dependencies
